# HADES public universe site

Public URL: https://ialirezaaa.github.io/hades/

This is a standalone bilingual (English/Persian) static website inside the existing public GitHub Pages repository. It does not replace the personal portfolio at the domain root.

## Files
- `index.html` and `fa/index.html` — semantic, crawlable pages;
- `assets/site.css` and `assets/site.js` — responsive presentation and color-copy interaction;
- `assets/B3424A5B-3375-4244-806C-EF9EAA60BDD1.jpeg` and `assets/IMG_7187(2).png` — exact owner-supplied originals, Git blob IDs unchanged;
- `downloads/` — EN/FA public descriptions and machine-readable owner-confirmed facts.

Source of truth for website copies: `site/public/hades/`. The root `hades/` path is a Pages publishing copy. Keep both identical when editing.

## Privacy and rights
Only owner-confirmed facts and public repositories are linked. Internal contracts, private project assets, approval documents, review boards, account data, credentials and unapproved master assets are deliberately excluded. The two raster logo sources are not SVG masters. Independent products maintain their own identities and licenses.

## QA
No build dependency. Test with a local static server; check relative links under /hades/ and /hades/fa/, mobile widths, keyboard navigation, logo Git blob SHA parity, download response codes and page SEO metadata. A web layout being public is not evidence of approval for all brand design choices.
