چیدمان سوژه روی استیج معماری

یکی از سه استیج موجود را انتخاب کنید، تصویر مجاز PNG/JPEG/WebP را از دستگاه خود بارگذاری کنید، جای آن را تغییر دهید و خروجی PNG با ابعاد اصلی یا SVG با لایه‌های جدا دریافت کنید. فایل به سرور فرستاده نمی‌شود.

PUBLIC REVIEW، نه FINAL. استیج‌های اصلی تغییر نمی‌کنند. لوگویی اضافه یا دستکاری نمی‌شود و هیچ تصویری به سرور فرستاده نمی‌شود. تنها رنگ تأییدشده #EF4B32 است؛ رنگ‌های خنثی و تایپ‌فیس پیشنهادی‌اند.

تصویر فقط در همین مرورگر استفاده می‌شود؛ حداکثر ۱۲ مگابایت. PNG شفاف مناسب‌تر است. بدون مجوز، تصویر مشتری را استفاده نکنید.

تراز کادر مستطیلی عکس است، نه سیلویت سوژه؛ حاشیهٔ شفاف را دستی اصلاح کنید. راهنمای A4 وکتوری · REVIEW

در حال بارگذاری استیج…

خروجی SVG شامل لایهٔ جداگانهٔ تصویر سوژه و همان SVG اصلی استیج به‌صورت تصویر تعبیه‌شده است؛ لوگوی وکتوری رسمی نیست. خروجی PNG ابعاد واقعی استیج را دارد. خطوط راهنما در خروجی نیستند.

OPEN: آزمون گوشی و چاپ فیزیکی، فونت واقعی و دارای مجوز Mikhak، حقوق استفاده از سوژه و تأیید FINAL. Pattern01 عمومی REVIEW، Pattern02 خصوصی و Pattern03 متوقف.
