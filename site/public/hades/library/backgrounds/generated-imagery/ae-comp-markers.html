After Effects composition markers

24 fps · 144 frames · 6 seconds · REVIEW

Install five duration markers into a duplicate composition. No layers, artwork, colors or keyframes are changed. Existing markers in the reference interval cause a safe stop.

Use

Duplicate your comp. Select it, set 24 fps, zero start time and at least 6 seconds duration. Choose File → Scripts → Run Script File, then select the JSX. Review the composition markers and undo if needed. The script does not read or write external files.

OPEN: native After Effects import, original footage contrast, Mikhak, physical print. Timing is a proposal, not final artwork.

پنج نشانگر مدت‌دار را به یک نسخهٔ کپی از کامپوزیشن اضافه کنید. لایه‌ها، تصویر، رنگ و کی‌فریم تغییر نمی‌کنند. وجود نشانگر قبلی در بازهٔ مرجع، اجرا را متوقف می‌کند.

روش استفاده

از کامپوزیشن کپی بگیرید. نرخ ۲۴ فریم، زمان شروع صفر و مدت حداقل ۶ ثانیه را تنظیم کنید. از مسیر File → Scripts → Run Script File فایل JSX را اجرا کنید. نشانگرها را بررسی کنید و در صورت نیاز Undo بزنید. اسکریپت فایل خارجی نمی‌خواند یا نمی‌نویسد.

OPEN: آزمون در خود افترافکت، کنتراست ویدیوی اصلی، فونت میخک و چاپ فیزیکی. زمان‌بندی پیشنهادی است، نه نسخهٔ نهایی.
