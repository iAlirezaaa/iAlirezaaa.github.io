Motion editor handoff

24 fps · 144 frames · 6 seconds · REVIEW

One offline package for editorial timing, framing and a reproducible composite. The artwork is not a new identity master.

Download ZIP · 13 files

Workflow

  1. Use one of three SVG frame guides for 16:9, 9:16 or 1:1.
  2. Import the bilingual SRT or WebVTT timing reference; CSV uses half-open frame intervals.
  3. Read the proposed landscape translation in the JSON file; portrait stays unchanged.
  4. With exact native PNG and matching source footage, use the Python/FFmpeg renderer. Check the output receipt and review contrast on actual frames.

Included

Three SVG guides, four subtitle tracks, one timing CSV, one placement JSON, one square indexed PNG derivative, one Python renderer, README and a file manifest.

Not included · OPEN

Native landscape and portrait RGBA PNGs, original MP4 footage, test MP4s, final contrast approval, NLE import, Mikhak and physical print. The square PNG is not a native RGBA master. Do not recolor or redraw any original mark.

ترتیب اجرا

  1. از یکی از سه راهنمای SVG برای قاب افقی، عمودی یا مربع استفاده کنید.
  2. نشانگرهای فارسی یا انگلیسی SRT و WebVTT را بررسی کنید؛ در CSV فریم پایان جزو بازه نیست.
  3. جابه‌جایی پیشنهادی عنوان افقی را از JSON بخوانید؛ عنوان عمودی بدون تغییر است.
  4. با PNG اصلی و ویدیوی منبع هم‌اندازه، از رندرر Python و FFmpeg استفاده کنید. رسید خروجی و کنتراست روی فریم‌های واقعی را بررسی کنید.

محتویات

سه راهنمای SVG، چهار فایل زیرنویس، یک CSV زمان‌بندی، یک JSON جای‌گذاری، یک PNG مربع ایندکس‌شده، یک رندرر Python، راهنما و فهرست فایل‌ها.

موجود نیست · OPEN

PNGهای اصلی RGBA افقی و عمودی، MP4های منبع و آزمایشی، تأیید نهایی کنتراست، ورود به نرم‌افزار تدوین، فونت میخک و چاپ فیزیکی. PNG مربع مستر RGBA نیست. هیچ نشان اصلی را بازطراحی یا تغییر رنگ ندهید.
