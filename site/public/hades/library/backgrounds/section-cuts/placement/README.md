## Using files
Open `/hades/library/backgrounds/section-cuts/placement/` or its FA version. Choose a ratio, replace title/subtitle, toggle guides and use **Export edited SVG**. Or open the source SVG in a vector editor and hide/delete `guide-overlay`. Keep the architectural `unchanged-source-architecture` group unchanged to retain the intended source design; copy field remains adjustable. For actual owner logo usage, place the **unaltered owner-supplied original PNG** on a detached dark plaque; do not redraw, trace, recolor, invert, or invent a new symbol. These templates contain **no** owner logo file; the plaque is only marked as a reservation.

Only sRGB `#EF4B32` is approved. All other swatches, copy, typography and spacing are PUBLIC REVIEW proposals; none is FINAL. The HTML uses system/Tahoma fallback, **not** a tested Mikhak font. UI is bilingual; SVG sample copy is English but the interactive editor accepts Persian. RTL glyph shaping/word overflow require manual scrutiny; physical phone and printing remain OPEN.

Technical: XML 1.0 SVG 1.1, external dependencies none, inline 3 edited text nodes and guide layer, original architecture paths copied from the three existing published SVGs. Artboard ratios: 1920×1080, 1080×1920, 1080×1080.
