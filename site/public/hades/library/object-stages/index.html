Usage and editable source

Each SVG uses editable vector groups and a hidden subject-placement guide. To reveal approximate subject limits, change the `subject-placement-guide-hidden` group's display from `none` to `inline`. These are backgrounds, not new HADES logos.

If an approved white owner mark is added later, keep its bytes unchanged and place it on an independent dark plaque over light backgrounds. Mikhak has not been tested. Real-phone legibility and physical printing remain OPEN.
