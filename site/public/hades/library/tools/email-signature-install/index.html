01 · Copy a formatted signature

  1. Open the editor and enter verified details. Select English or Persian and choose original image or text-only.
  2. Press Copy rich signature. The browser must permit rich clipboard access over HTTPS.
  3. If blocked, press Select rendered signature, then copy the selected preview with Ctrl+C / Cmd+C. Copy HTML only copies source code — not formatted text.
  4. Paste into the email-client signature editor. Send yourself a test email before using it commercially.

۰۱ · کپی امضای قالب‌بندی‌شده

  1. نام و عنوان تأییدشده را وارد کنید و زبان یا نمایش تصویر اصلی را انتخاب کنید.
  2. دکمهٔ Copy rich signature را بزنید. مرورگر باید اجازهٔ Clipboard با محتوای HTML را بدهد.
  3. اگر مجوز داده نشد، Select rendered signature را بزنید و پیش‌نمایش انتخاب‌شده را کپی کنید. گزینهٔ Copy HTML تنها کد منبع را کپی می‌کند.
  4. محتوا را در تنظیمات امضای ایمیل جایگذاری و یک ایمیل آزمایشی ارسال کنید.

02 · Gmail

  1. On Gmail desktop, open Settings → See all settings → General → Signature.
  2. Create or choose a signature, paste the formatted content and save changes at the bottom.
  3. Choose defaults for new messages and replies explicitly. Mobile Gmail apps may require a separate mobile signature and may not preserve HTML.

۰۲ · جیمیل

  1. در نسخهٔ دسکتاپ به Settings → See all settings → General → Signature بروید.
  2. امضای جدید بسازید، محتوای قالب‌بندی‌شده را جایگذاری و تغییرات را ذخیره کنید.
  3. گزینهٔ پیام جدید و پاسخ را مشخص کنید. نسخهٔ موبایل ممکن است امضای جداگانه بخواهد و HTML را حفظ نکند.

03 · Outlook

  1. For Outlook on the web/new Outlook, look in Settings → Accounts → Signatures or Mail → Compose and reply (version-dependent).
  2. For classic Outlook desktop, use File → Options → Mail → Signatures.
  3. Paste and test received message in light/dark mode. Desktop, web and mobile versions can sanitize HTML differently.

۰۳ · اوت‌لوک

  1. در نسخهٔ وب یا جدید، بخش Settings → Accounts → Signatures یا Mail → Compose and reply را بررسی کنید.
  2. در نسخهٔ دسکتاپ قدیمی از File → Options → Mail → Signatures وارد شوید.
  3. امضای دریافتی را در حالت روشن و تاریک بررسی کنید. رفتار نسخه‌های مختلف Outlook یکسان نیست.
