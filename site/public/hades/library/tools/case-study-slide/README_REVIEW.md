## Usage / استفاده

1. Download the SVG you need and open in Inkscape, Illustrator, or an SVG-capable editor.
2. Replace title, one-line overview, challenge, approach, and outcome. Preserve text inside the safe frame; check visual bounds and actual font fallback.
3. Preserve independent product names and visual identities. No project logos, private assets or customer details are bundled.
4. Optional HADES 3RD attribution is hidden by default; enabling it requires separately confirmed rights and should remain low prominence (~10% hierarchy guidance, *not* an approved fixed-size metric).
5. If a real owner-original HADES mark is necessary in a HADES-owned composition, reference the unmodified approved raster original separately; do not fabricate a new vector logo.
6. Review on real 320/390/430px devices and at native 1920×1080 output. No "FINAL" status without owner review.
