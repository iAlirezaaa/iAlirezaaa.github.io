# HADES B03 — A4 Letterhead · working files · REVIEW
A fully editable blank correspondence master, not a photo mockup.
- Two **210×297mm** self-contained SVGs: Dark (existing owner-original raster symbol isolated to alpha and placed small); Light (deliberately omits a white mark rather than recoloring).
- Editable text, stroke paths, vector arc background, separate SVG groups (`layer-background`, `layer-pattern`, `layer-logo`, `layer-typography`, `layer-accent`).
- Source-driven **2480×3508 PNG at nominal 300dpi**, **five-layer 1240×1754 PSD at nominal 150dpi** (each layer raster, SVG text editable), contact sheet, original-derived mark source, ZIP and Python build script.
- Source original `IMG_7187(2).png`, SHA256 `79867ef2cea0777a277df45a2754ea012ff552d466963f8cb831e5940a5cafb7`; source-derived mark SHA256 `8d3d0e1ac89660f8a1ed7e135d878dc6f223590f91dd7f9a7ad8dba47f00f164` (exact previous B01 symbol). Not an official vector logo.
- No fabricated contact details. No simulated client address or fake trademark authority.
- Approved: Classic/Modern as one system, vermilion **#EF4B32** only. All supporting hues, Inter/Noto Serif/Mikhak font choices, precise page layout, paper, profile, bleed and print signoff remain **REVIEW**.
- Persian glyph proof was attempted but the CairoSVG renderer did not shape that example correctly; optional Persian copy is therefore left for later browser/Mikhak qualification rather than shipping squares on the template.
- Website: https://ialirezaaa.github.io/hades/brand-kit/letterhead/ and https://ialirezaaa.github.io/hades/fa/brand-kit/letterhead/
