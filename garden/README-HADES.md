# باغ دیجیتال هادس

ساختار بخش فارسیِ نوشته‌ها و یادداشت‌های سایت بر پایهٔ قالب اصلی [Digital Garden](https://github.com/oleeskild/digitalgarden) است؛ افزونهٔ [Obsidian Digital Garden](https://github.com/oleeskild/obsidian-digital-garden) می‌تواند یادداشت‌ها را در همین مخزن منتشر کند.

- [ورود به باغ](https://ialirezaaa.github.io/fa/garden/)
- [نوشته‌ها و مقاله‌ها](https://ialirezaaa.github.io/fa/blog/)
- [منبع یادداشت‌ها](src/site/notes/)

## انتشار از Obsidian

در Obsidian، افزونهٔ **Digital Garden** را از Community plugins نصب و فعال کن. تنظیمات مقصد برای این سایت:

| تنظیم | مقدار |
| --- | --- |
| GitHub username | `iAlirezaaa` |
| Repository name | `iAlirezaaa.github.io` |
| Publish branch | `main` |
| Content base directory / Subfolder | `garden` |
| Garden URL / Base URL | `https://ialirezaaa.github.io/fa/garden/` |

توکن دسترسی را فقط در تنظیمات افزونهٔ روی دستگاه خودت وارد کن. توکن در سورس سایت یا فایل `.env` قرار نمی‌گیرد. بخش **Content base directory** به نسخه‌ای از افزونه نیاز دارد که انتشار داخل زیردایرکتوری را پشتیبانی می‌کند.

برای انتشار هر یادداشت، مشخصات ابتدای فایل می‌تواند این‌طور باشد:

```yaml
---
title: یادداشت من دربارهٔ تصویرسازی
dg-publish: true
aliases:
  - تصویرسازی
tags:
  - هوش-مصنوعی
---
```

بین یادداشت‌ها از `[[نام یادداشت]]`، `[[نام یادداشت|متن دلخواه]]` و `[[نام یادداشت#عنوان بخش]]` استفاده کن. سپس از Command Palette فرمان **Digital Garden: Publish Single Note** یا فرمان انتشار چند یادداشت را اجرا کن. تغییرات در GitHub ساخت نسخهٔ جدید سایت را فعال می‌کنند.

فقط صفحهٔ ورودی باغ باید `dg-home: true` داشته باشد؛ برای یادداشت‌های عادی این گزینه را اضافه نکن. یادداشت‌های بدون `dg-publish: true` وارد خروجی سایت نمی‌شوند. `public: false` و `draft: true` نیز انتشار را متوقف می‌کنند. مخزن حاضر عمومی است؛ فایل خصوصی را به خود مخزن عمومی اضافه نکن، حتی اگر قرار نیست در سایت نمایش داده شود.

## فارسی و مطالعه

صفحه‌ها و کنترل‌ها راست‌به‌چپ هستند. متن کد و نشانی‌ها جهت مستقل دارند. قلم اصلی **میخک** از خود سایت دریافت می‌شود؛ فایل اصلی و مجوز OFL در `src/site/fonts/` قرار دارند. جست‌وجو برای «ی/ي»، «ک/ك»، رقم‌های فارسی و نیم‌فاصله نرمال‌سازی می‌شود. تاریخ‌ها شمسی نمایش داده می‌شوند.

فهرست پوشه‌ها، جست‌وجو، پیش‌نمایش پیوندها، گراف محلی و کلی، پیوندهای ورودی، فهرست مطالب و تنظیمات مطالعه در مقاله‌ها و یادداشت‌ها از یک پوسته استفاده می‌کنند. روی موبایل، فهرست و اطلاعات صفحه از دکمه‌های جدا باز می‌شوند.

## ساخت سایت و نگهداری

```sh
npm ci --prefix site
npm ci --prefix garden
npm --prefix site run build
node site/scripts/postbuild.mjs
node site/scripts/verify-blog-garden.mjs
node site/scripts/validate-site.mjs
```

منبع قابل ویرایش یادداشت‌ها `garden/src/site/notes/` است. منبع مقاله‌های فعلی `site/public/fa/blog/entries.js` باقی می‌ماند و هنگام ساخت به قالب باغ وارد می‌شود. مسیرهای مقاله‌ها، دسته‌بندی‌ها، برچسب‌ها و تصاویر قبلی حفظ شده‌اند. فایل‌های `fa/` در ریشهٔ مخزن خروجی انتشار هستند؛ آنها را دستی ویرایش نکن.

فایل `garden.config.json` تنظیمات پیش‌فرض فارسی را نگه می‌دارد. `.env` فقط برای تنظیمات عمومی ظاهر است و افزونه می‌تواند آن را به‌روزرسانی کند. ساخت ابتدا یادداشت‌های مجاز را در پوشه‌ای موقت جدا می‌کند و بعد قالب Eleventy را اجرا می‌کند. هیچ یادداشت مرتبطی صرفاً به دلیل پیوندخوردن خودکار منتشر نمی‌شود.

پوستهٔ فارسی در فایل‌های `src/site/_includes/components/hades*`، استایل اختصاصی و `src/site/scripts/hades.js` نگهداری می‌شود. هنگام به‌روزرسانی قالب اصلی، تغییرات را در pull request بررسی و همین آزمون‌ها را اجرا کن.

این راهنما مقصد انتشار را آماده می‌کند. اتصال Obsidian روی دستگاه مالک باید در خود افزونه انجام شود؛ این مخزن حاوی هیچ توکن اتصال نیست.
