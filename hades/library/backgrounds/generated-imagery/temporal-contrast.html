Temporal contrast

Audit every decoded frame against a fixed transparent title. A still-frame pass does not guarantee video readability.

1. Run locally

Requires FFmpeg, ffprobe, Python, NumPy and Pillow. Use a same-ratio RGBA title from the lower-third editor.

Download Python audit · Title editor

python -m pip install numpy pillow
python temporal_contrast.py clip.mp4 title.png report.json

2. Inspect the report

Near-opaque non-accent pixels only; 4.5:1 threshold. Decorative vermilion, edge pixels, HDR, physical print and human/device reading are not certified. No uploads. Proposed neutrals and type; no logo added.
