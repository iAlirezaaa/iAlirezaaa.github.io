Native alpha sequence for editing

Generate numbered native RGBA PNG frames with straight alpha from the existing PNG and its manifest. Only the whole-layer alpha changes; RGB and dimensions remain unchanged.

Download and run

Python exporter · Transparent source pack

Extract the source pack. Install Python and Pillow, then run the command in the extracted folder with the script present. The output file must not already exist.

python -m pip install Pillow
python alpha_sequence.py HADES_Motion_Safe_Closing_EN_16x9_PUBLIC_REVIEW.png manifest.REVIEW.json output.zip --fps 24 --seconds 3

Choose 24, 25 or 30 fps and 3, 5 or 8 seconds; all three ratios and both languages via the input PNG. Example: 72 frames, 0000 through 0071. First and last frames are fully transparent.

Editing handoff

Extract the output ZIP; import the first PNG as an image sequence at the selected fps, interpret alpha as straight/unmatted, and place above footage. Do not apply a second fade. Actual editor import remains OPEN.

Only #EF4B32 is approved; neutrals and typography are proposed. Physical phone, micro-recognition, print and genuine Mikhak OPEN. Independent product credit requires permission.
