# HADES A4 Letter RTF — FA / EN • REVIEW

This folder includes two actual editable Office-compatible **RTF** letter templates for Microsoft Word and LibreOffice, alongside the existing bilingual HTML editor. Use them to replace seven working placeholders. Their page size is A4 (210 × 297 mm); no invented business contacts or client details. Typographic HADES THE THIRD text is a label, **not an official new logo**; deliberately no substitute graphic has been drawn or embedded. Insert only an unmodified owner-supplied authorized original if a graphical mark is required.

How to use: download RTF, open in Word or LibreOffice Writer, replace the bracketed sample text, check the font and RTL paragraph direction, insert the verified original raster logo only if appropriate, then save as DOCX/ODT or export a one-page A4 PDF. The source files are Office documents, not final press files. Do not treat the simple HADES text in the upper margin as a vector logo.
