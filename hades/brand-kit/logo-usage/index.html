01

Preserve original identity

Use original raster source bytes. Keep aspect ratio, material, colour and original artwork untouched. Any crop must remove only unused outer margins; record and review it.

02

Micro mark ≠ micro contact text

A tiny mark is a quiet identity cue, not a reliable carrier of tiny internal lettering. Typeset essential names and contact information separately in readable editable text.

03

Size, spacing and contrast

No universal approved minimum logo width exists. Validate each placement at its actual physical or pixel size, including 320/390/430 CSS px views. Keep generous negative space and visible separation.

04

Colour and expression

Only vermilion #EF4B32 and coordinated Classic/Modern direction are owner-confirmed. Supporting neutrals, metallics, typography, finishes and layouts remain proposals. Never recolour a source logo.

05

Use the correct file

PNG for pixel-target previews, layered PSD for source editing, PDF for printer-reviewed physical documents, SVG/HTML for editable compositions. An SVG layout is NOT an official vector-logo master.

06

Rights and release

Keep individual layouts REVIEW until separately approved. Pattern 01 is publicly visible as REVIEW; Pattern 02 is PRIVATE REVIEW; Pattern 03 is on hold. Independent products are not rebranded as HADES.

Why is there no official SVG logo?

The available logo sources are raster. Editable SVG files in the library are APPLICATION COMPOSITIONS referencing original images, not reconstructed or certified official vector logo masters.
