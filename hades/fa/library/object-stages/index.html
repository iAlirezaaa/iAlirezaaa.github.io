راهنمای استفاده

هر SVG شامل گروه‌های وکتوری مستقل و یک گروه راهنمای جایگاه شیء است که پیش‌فرض پنهان است. برای مشاهدهٔ محدودهٔ تقریبی سوژه، در کد مقدار display گروه subject-placement-guide-hidden را از none به inline تغییر دهید. این فایل لوگو نیست.

اگر نشان سفید اصلی را به یک طرح روشن اضافه می‌کنید، فقط تصویر مالک را بدون هیچ تغییر روی پلاک تیرهٔ مستقل بگذارید. برای متن فارسی، فونت Mikhak در این خروجی آزمون نشده است. تشخیص روی گوشی واقعی و چاپ فیزیکی هنوز OPEN است.
